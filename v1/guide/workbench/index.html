    Workbench¶

    The Workbench is the panel on the left of the map that manages every dataset currently active. Anything you add from the Data Catalogue or My Data lands here.

    What the Workbench does¶

    • Toggle datasets — turn datasets on or off as needed.
    • Adjust opacity — modify the transparency of a dataset.
    • Compare data — use split screen mode to place datasets side by side.
    • Temporal navigation — step through time series data where a dataset provides it.

    Managing datasets¶

    Control Effect
    Remove All Clears every dataset from the workbench
    Collapse All Minimises all datasets for a cleaner view
    Three-dot icon Removes one specific dataset, or opens its style editor and export options
    Checkbox Turns an individual dataset on or off
    Dataset dropdown Zoom, adjust opacity and view details for that dataset

    Ideal Zoom

    The Ideal Zoom option in a dataset's dropdown moves the map to the view that best frames that dataset — useful when you have added a layer whose extent you do not know.

    Styling from the Workbench¶

    The display variable control decides which attribute a dataset is drawn by. For finer control, open the three-dot menu, choose Edit Style, make your changes and click Done.

    See Styling a dataset for a worked example using the E-flow Monitoring and Forecasting dataset.

    Comparing datasets¶

    The compare tool works directly against the Workbench contents — see Compare feature in Map Tools.
