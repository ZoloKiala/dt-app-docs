    Map Tools¶

    The controls down the right-hand side of the map handle orientation, navigation, comparison and measurement; the top bar carries Map Settings and Share / Print; and v2 adds two new tools — an AI chatbot and a SWAT extraction tool.

    Map Settings¶

    Map Settings (top bar) customises how the map is drawn.

    • Map View — 3D Terrain, 3D Smooth or 2D.
    • Show Terrain on the — Left / Both / Right, with an option so terrain hides underground features.
    • Base Map — v2 offers a wider set than the 2024 release: Bing Aerial with Labels (default), Bing Aerial, Bing Roads, OpenStreetMap, OpenTopoMap, Esri World Imagery, Esri Topographic, Dark Matter, Positron (Light) and Natural Earth II.
    • Timeline → Always show — keeps the time-series controls on screen.
    • Image Optimisation — use native device resolution.
    • Map Quality — a Quality ↔ Performance slider.

    View controls¶

    The Change view control (the ring-and-cross icon) rotates the map through 360°, and a double-click resets it. Beneath it:

    Control Action
    Home Returns to the default globe view
    + / – Zoom in / out (the mouse wheel also zooms)
    Location Live location tracking — click Allow in the popup
    Pan Drag the map with the left mouse button

    Compare¶

    The Compare tool (Enable side-by-side comparison between two different sets of data) puts two datasets side by side in split-screen mode.

    1. Click Compare to enter split-screen mode.
    2. Choose the two datasets to compare.
    3. Drag the split bar to align them; assign each dataset to Left, Right or Both.

    Terrain note

    Terrain layers can obscure underground features — relevant depending on the datasets being compared.

    Pedestrian mode¶

    Pedestrian Mode gives a street-level view for detailed exploration.

    Use the control tool to rotate the view; Space moves forward and Shift moves backward.

    Measure¶

    The Line Measure tool (Measure distance between locations) measures the distance between two or more points on the map.

    Water Copilot chatbot¶

    New in v2

    Open Chatbot (bottom-right of the map) launches Water Copilot, an AI assistant. Ask questions about the basin and its data in plain language and get guided answers and navigation help. The assistant opens in a panel beside the map.

    SWAT Extraction Tool¶

    New in v2

    The SWAT Extraction Tool queries modelled flows from the SWAT hydrological model for a specific river channel.

    • Select Flow Type — e.g. Natural Flows.
    • Channel ID — the channel to query.
    • Start Date / End Date — the period of interest.
    • Condition — a filter on the flow condition.
    • FETCH DATA — retrieves the modelled series; the MAP / TABLE / HELP / PROBFLO tabs switch between the map picker, the results table, help, and the ProbFlo view.

    Feedback¶

    The Give Feedback tool sends comments or questions directly to the developers.

    Data attribution and basemap selection¶

    Along the bottom of the map are data attribution, the basemap selector, and the disclaimers that apply to the data in use, plus a live Lat / Lon / Elev readout and a scale bar.
