# Reference

## Source document

This site is derived from **DT_03 — User Guide: TerriaJS Digital Twin**,
*Development of a TerriaJS Portal Showcasing the Digital Twin (DT) — Case Study
of the Limpopo River Basin*, dated **August 2024**.

The original Word document is kept alongside this site at
`DT_03_UserGuide_Terra_JS_Digital Twin.docx`.

!!! note "Figure numbering"
    Figures have been renumbered sequentially for this edition. The source
    document contained gaps and repeated numbers (for example, two figures
    labelled 14 and three labelled 54), so figure numbers here will not match
    the Word original one-for-one. The screenshots themselves are unchanged.

## Portal version

- **Portal:** <https://limpopo.digitaltwins.iwmi.org/>
- **TerriaMap version:** `0.4.1`
- **TerriaJS version:** `8.9.5`
- **Build date:** 2026-05-15
- **Platform components:** Cesium ion for 3D mapping, data attribution and base
  map selection.
