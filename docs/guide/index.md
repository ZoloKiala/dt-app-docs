# User Guide

This guide walks through the Limpopo WebGIS Portal interface, feature by
feature, in roughly the order you meet them.

| Page | Covers |
| --- | --- |
| [Getting Started](getting-started.md) | The homepage, location search and opening the map |
| [Data Catalogue](data-catalogue.md) | Browsing, searching, previewing and adding datasets |
| [Dataset Themes](datasets.md) | What each of the five thematic categories contains |
| [My Data](my-data.md) | Adding your own local files and web services |
| [Workbench](workbench.md) | Managing the layers currently on the map |
| [Map Tools](map-tools.md) | View controls, compare, pedestrian mode, measuring, settings |
| [Stories & Sharing](sharing.md) | Building narratives and sharing or printing the map |
| [Help & Support](help-support.md) | Tours, guides, related maps, feedback and version info |

!!! tip "Two ways to learn the interface"
    The portal ships with a built-in guided **Take the Tour** walkthrough and a
    **Getting Started with the Map** video. Both are reachable from the
    [Help feature](help-support.md#the-help-feature) at any time — you do not
    have to leave the map to use them.
