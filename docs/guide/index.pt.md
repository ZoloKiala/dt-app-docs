# Guia do Utilizador

Este guia percorre a interface do Portal WebGIS do Limpopo, funcionalidade a
funcionalidade, aproximadamente pela ordem em que as encontra.

!!! info "Nomes dos comandos"
    A interface do portal está em inglês. Os nomes dos botões e painéis são
    mantidos em inglês — tal como aparecem no ecrã — com a tradução entre
    parênteses na primeira utilização.

| Página | Conteúdo |
| --- | --- |
| [Primeiros Passos](getting-started.md) | A página inicial, a pesquisa de localizações e a abertura do mapa |
| [Catálogo de Dados](data-catalogue.md) | Explorar, pesquisar, pré-visualizar e adicionar conjuntos de dados |
| [Temas dos Dados](datasets.md) | O que contém cada uma das cinco categorias temáticas |
| [Os Meus Dados](my-data.md) | Adicionar ficheiros locais e serviços web próprios |
| [Área de Trabalho](workbench.md) | Gerir as camadas atualmente no mapa |
| [Ferramentas do Mapa](map-tools.md) | Controlos de vista, comparação, modo peão, medição e definições |
| [Histórias e Partilha](sharing.md) | Construir narrativas e partilhar ou imprimir o mapa |
| [Ajuda e Apoio](help-support.md) | Visitas guiadas, guias, mapas relacionados, comentários e versão |

!!! tip "Duas formas de aprender a interface"
    O portal inclui uma visita guiada interativa — **Take the Tour** (*Fazer a
    visita*) — e um vídeo **Getting Started with the Map** (*Começar a utilizar
    o mapa*). Ambos estão acessíveis a partir da
    [funcionalidade Help](help-support.md#a-funcionalidade-help) a qualquer
    momento, sem sair do mapa.
