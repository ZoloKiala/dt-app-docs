# Dataset Themes

The catalogue groups data into five thematic categories. This page walks
through each one and what you will find inside. The mechanics of previewing,
adding and styling any dataset are the same throughout — see
[Data Catalogue](data-catalogue.md).

## Natural Basin Characteristics

Opening this category's dropdown reveals its sub-collections.

### Physiography

Lists elevation and topography, basin and sub-basin boundaries, the channel
network, and 3D point cloud data.

Three controls are worth knowing on this view:

- **Dropdown menu** — display dataset features such as Ideal Zoom, data
  details and display variables.
- **Three-dot icon** — edit the dataset's style, export the map, or remove the
  dataset from the map view and workbench.
- **Vertical icons** — positioned along the right of the map; hover over any
  of them for a description of what it does.

<figure markdown="span">
  ![Channel network data of the Limpopo basin](../assets/images/image16.png)
  <figcaption>Figure 22: Channel network data for the Limpopo basin area.</figcaption>
</figure>

The **display variable** control also opens up charting and filtering for the
data.

### 3D point clouds

High-resolution 3D point cloud data for river systems in South Africa,
currently covering the **Oliphants River** and the **Crocodile River System
(Upper and Lower)**. The data was collected by drone survey.

<figure markdown="span">
  ![3D Point Clouds dataset previewed](../assets/images/image17.png)
  <figcaption>Figure 23: The 3D point clouds dataset, previewed.</figcaption>
</figure>

Click a dataset to preview it and add it to the map. Beneath the preview sits
the detailed description and the rest of the dataset's metadata.

### Land cover and land use

Contains the **Land Use**, **Irrigated Mapping** and **Vegetation Condition
Index (VCI)** datasets.

<figure markdown="span">
  ![Land use data](../assets/images/image18.png)

</figure>

Some of these datasets offer advanced features:

- **Time series** — for datasets such as irrigated mapping, use the time
  series controls beneath the map view and in the workbench panel. The left and
  right arrows step through time.
- **Map styles** — change and customise map styles as needed for flexible
  visualisation.

## Ecosystems

Datasets related to the ecosystems of the Limpopo River basin:

| Dataset | Contents |
| --- | --- |
| **E-flow Regions** | Various ecological flow regions |
| **E-flow Monitoring and Forecasting** | Current and forecast ecological flows |
| **E-flow Alert Levels** | Different levels of ecological flow alert |
| **SWAT Incremental Contributions** | Incremental contributions from the SWAT model |
| **E-flow Warnings** | Alerts related to ecological flow conditions |
