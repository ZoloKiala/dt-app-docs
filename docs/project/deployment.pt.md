# Implementação e Manutenção

## Implementação na AWS

O portal está implementado na AWS, tirando partido da sua infraestrutura
escalável para garantir elevada disponibilidade e desempenho.

O processo de implementação incluiu:

1. **Configuração do servidor de testes** — instalação e testes iniciais
   realizados num servidor de testes dedicado.
2. **Migração para o servidor de produção** — concluídos os testes com
   sucesso, o portal foi migrado para o ambiente de produção.

## Manutenção e apoio

A manutenção contínua responde aos problemas surgidos após a implementação:

- **Correção de erros e atualizações** — são aplicadas atualizações regulares
  para corrigir erros e incorporar novas funcionalidades.
- **Apoio ao utilizador** — existe um canal de apoio para ajudar os
  utilizadores com questões ou problemas.
