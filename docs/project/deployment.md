# Deployment & Maintenance

## AWS deployment

The portal is deployed on AWS, using its scalable infrastructure to ensure high
availability and performance.

The deployment process covered:

1. **Test server configuration** — initial setup and testing carried out on a
   dedicated test server.
2. **Production server migration** — once testing succeeded, the portal was
   migrated to a production environment.

## Maintenance and support

Ongoing maintenance addresses issues arising after deployment:

- **Bug fixes and updates** — regular updates are applied to fix bugs and
  incorporate new features.
- **User support** — a support channel is established to assist users with
  queries or issues.
