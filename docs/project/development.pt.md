# Processo de Desenvolvimento

## Desenvolvimento iterativo e incremental

O Portal WebGIS foi construído de forma iterativa e incremental, com melhoria e
refinamento contínuos orientados pelo retorno das partes interessadas. Cada
fase concentrou-se na integração de novas funcionalidades, melhorando ao mesmo
tempo as já existentes.

## Fase 1 — Identificação e integração das fontes de dados

- **Auditoria e classificação de dados** — auditoria abrangente das fontes de
  dados existentes, categorizadas por tipo e relevância.
- **Prototipagem** — desenvolvimento de protótipos iniciais para testar os
  processos de integração de dados.

## Fase 2 — Implementação e testes

- **Desenvolvimento do backend** — implementação das cadeias de ingestão e
  processamento de dados.
- **Desenvolvimento do frontend** — criação dos componentes interativos da
  interface para visualização de dados.
- **Testes de integração** — testes rigorosos para garantir que todos os
  componentes funcionam em conjunto sem falhas.

## Fase 3 — Melhoria contínua

- **Integração do retorno dos utilizadores** — iteração contínua com base nos
  comentários recebidos, melhorando tanto a interface como as funcionalidades.
- **Documentação e formação** — elaboração de manuais de utilizador e sessões
  de formação para os utilizadores finais.

!!! note "Ciclo de retorno"
    O [formulário de comentários](../guide/help-support.md#comentarios)
    integrado no portal é a ponta viva deste processo — as observações dos
    utilizadores chegam diretamente à equipa de desenvolvimento.
