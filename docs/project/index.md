# Project Overview

The WebGIS Portal delivers a comprehensive and user-friendly interface for
visualising climatic and water resource datasets. It aggregates and interpolates
data from multiple sources — satellite imagery, in-situ sensor data and
numerical model outputs — stored primarily on AWS.

## Background

The WebGIS Portal Phase 2 project, developed for the International Water
Management Institute (IWMI), provides an advanced geospatial web portal for
visualising and interacting with spatial datasets relevant to the Limpopo River
basin. The platform features a Digital Twin (DT) of the basin.

Phase 2 builds on the foundation established in Phase 1, leveraging the
TerriaJS framework — an open-source platform known for web-based geospatial
catalogue exploration. The portal draws inspiration from platforms such as
Digital Earth Africa (DE Africa) and incorporates improvements based on
Phase 1 feedback.

## Objectives

| Objective | Description |
| --- | --- |
| **Geospatial visualisation** | Develop a web application forming the foundation of the Digital Twin, to visualise and interact with spatial data specific to the Limpopo River basin |
| **Mapping functionalities** | Implement essential mapping features such as zoom, pan and layer control |
| **Data integration** | Integrate diverse geospatial data sources for accurate, up-to-date information |
| **User experience** | Offer a user-friendly interface for seamless navigation and data exploration |
| **Cross-browser compatibility** | Ensure the portal works effectively across different browsers and devices |

## Scope

The portal encompasses the following key components:

- **Responsive portal** — an interactive WebGIS portal designed for diverse
  devices.
- **Geospatial data integration** — aggregated data from APIs and other
  sources.
- **Advanced visualisation** — tools for visualising data related to irrigated
  areas.
- **AI-driven chatbot** — a chatbot to assist users with queries and
  navigation.
- **Enhanced time series maps** — fixed and enhanced time series maps for
  better data analysis.
- **Additional shapefiles** — inclusion of additional shapefiles for
  comprehensive data coverage.
- **AWS deployment** — hosting on AWS for high availability and scalability.
