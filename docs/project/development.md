# Development Process

## Iterative and incremental development

The WebGIS Portal was built iteratively and incrementally, with continuous
enhancement and refinement driven by stakeholder feedback. Each phase focused
on integrating new features while improving existing functionality.

## Phase 1 — Data source identification and integration

- **Data audit and classification** — a comprehensive audit of existing data
  sources, categorised by type and relevance.
- **Prototyping** — early prototypes developed to test the data integration
  processes.

## Phase 2 — Implementation and testing

- **Backend development** — implementation of the data ingestion and
  processing pipelines.
- **Frontend development** — creation of the interactive UI components for
  data visualisation.
- **Integration testing** — rigorous testing to ensure all components work
  together seamlessly.

## Phase 3 — Continuous improvement

- **User feedback integration** — continuous iteration based on user feedback,
  improving both the UI and the functionality.
- **Documentation and training** — development of user manuals and training
  sessions for end users.

!!! note "Feedback loop"
    The in-portal [Feedback form](../guide/help-support.md#feedback) is the
    live end of this process — user comments from the portal feed directly back
    to the development team.
